# 🖨️ Printer Troubleshooting Guide

> 💼 This document demonstrates practical troubleshooting knowledge for IT Support / Helpdesk roles.

---

## 📄 Paper Jams or Creased Paper
- Power cycle the printer (turn OFF and ON).
- If not resolved, unplug and open the printer.
- Remove trays and clear any stuck paper.
- Ensure correct paper type (avoid too thin/thick or humid paper).
- Clean or replace dirty/cracked rollers (use isopropyl alcohol for temporary fix).
- Check fuser overheating; allow cooling before handling.
- Inspect full paper path (especially duplex printers).

---

## 🧾 Blank Pages Printing
- Check if toner is empty or faulty → replace cartridge.
- Remove sealing tape from cartridge if present.
- Check transfer corona wire → replace if faulty.

---

## 📥 Paper Not Feeding
- Check paper quality and condition.
- Clean rollers.
- Reset printer.
- Use maintenance kit if required.

---

## 📚 Multiple Pages Feeding (Misfeed)
- Clean separation pad.
- Use thicker paper (20 lb or higher recommended).

---

## ⚠️ Error Codes
- Read error message on printer display (OCP).
- Refer to printer manual/documentation for details.

---

## 🧠 Out of Memory Error
- Enable **"Start Printing Immediately"** setting.
- Restart Print Spooler service.
- Reduce file/image size.
- Upgrade printer RAM if necessary.

---

## 🖥️ No Display on Printer (OCP)
- Check if printer is ON or in sleep mode.
- Verify power connection.
- Check internal display connector (rare case).

---

## 📏 Lines, Streaks, Smearing Issues
- Replace toner cartridge.
- Clean corona wires.
- Check drum for damage.
- Replace fuser if toner is not sticking properly.

---

## 🌫️ Faded Prints
- Replace ink/toner.
- Clean cartridge head.
- Check fuser and adjust humidity if needed.

---

## 🔤 Garbage or Garbled Output
- Install correct printer driver.
- Avoid incompatible or “close” drivers.
- Replace formatter board if faulty.

---

## 👻 Ghosted Image
- Replace drum or toner cartridge.
- Check and replace fuser if needed.

---

## 🔁 Double / Echo Images
- Align print heads.
- Check drum or fuser.
- Update/reinstall drivers and firmware.

---

## 🔊 Grinding Noise
- Replace defective toner cartridge.
- Check for paper jam or carriage issues.

---

## 🌐 Connectivity Issues
- Ensure printer is powered ON.
- Check USB/network connection.
- Install correct driver.
- Verify IP address.
- Set printer as default if required.

---

## 🚫 Access Denied
- Grant user permission to access printer.
- Ensure administrative rights for installation.

---

## 📂 Print Queue Stuck
- Restart stuck document.
- Restart Print Spooler service.
- Reinstall driver if required.

---

## 🎨 Incorrect Colors
- Check ink/toner levels.
- Run printer calibration.
- Verify PostScript/RIP support.

---

## 📎 Finishing Issues (Staple / Punch)
- Align paper guides properly.
- Ensure staples are available.
- Check driver and finishing settings.
- Empty punch tray.

---

## 📐 Incorrect Paper Size / Orientation
- Verify correct paper is loaded.
- Check OS print settings (size & orientation).

---

## 📊 Multiple Failed Jobs in Logs
- Reset printer.
- Clear print queue.
- Restart spooler.
- Check print server/OS issues.

---

## ⚙️ Unable to Install Printer
- Verify physical/network connection.
- Ensure printer has valid IP address.
- Start Print Spooler service.
- Install/update correct driver.
- (Advanced) Configure registry settings if required.
